# Glossário

> Versão 1.1 · 26/11/2026 · gerado a partir dos Prompts 01–04 da Stack Multiagentes (Prompt 04, Anexo A, tem prioridade). v1.1 (DOC, AH-0004): PR real no GitHub no lugar de “PR local”.


| Termo | Significado |
|---|---|
| AH | Aprovação humana (N3), por AH-nnnn, do Thiago Melo ou de designado por escrito |
| DoR / DoD | Definition of Ready / Definition of Done (`governanca/dor-dod.md`) |
| G0–G8 | Gates: G0 Entrada · G1 Escopo/proposta · G2 Planejamento · G3 Contratos e dados · G4 Code Review · G5 Qualidade · G6 Pré-liberação (inclui AH de publicação) · G7 Implantação verificada · G8 Encerramento |
| MSG-SOL / MSG-RET / MSG-COL / MSG-BLQ / MSG-CONS / MSG-AH | Contratos de mensagem entre agentes (`modelos/`) |
| N1–N4 | Níveis de autonomia (`governanca/politica-autonomia.md`) |
| P0–P3 | Severidade de incidentes e defeitos (Crítico, Alto, Médio, Baixo) |
| Imediata / Alta / Normal / Baixa | Classes de prioridade de demanda |
| R1–R3 | Classe de risco (baixo, médio, alto) |
| SSOT | Fonte única de verdade |
| Tipo A / B / C | Incidente operacional / técnico especializado / defeito de software |
| Espelho CSV | Cópia da planilha em `planilha-operacao/`, uma aba por arquivo, usada até o conector do Google Sheets ser ativado |
| PR | PR real no GitHub: ramo `doc/<ID>-slug` ou `feat/<ID>-slug`, PR aberto pelo autor, revisão do CR quando aplicável, merge pelo dono da área (protocolo-memoria v1.2, AH-0004) |
| PR local | Termo anterior à AH-0004: ramo `doc/<ID>-slug` + MSG-COL ao dono, que fazia o merge. Substituído pelo PR real no GitHub |
